# پوشهٔ دارایی‌ها

## لوگوی کانال

لوگوی کانال را با یکی از این نام‌ها اینجا بگذارید:

```
logo.png    (سفارش می‌شود — پس‌زمینهٔ روشن را نگه می‌دارد)
logo.jpg
logo.jpeg
```

این لوگو در بالای جلدِ هر نوا نشانده می‌شود، با نام مداح و بیتی
از نوا در زیرش.

**اندازهٔ سفارشی:** مربع، دست‌کم ۴۰۰×۴۰۰ نقطه. برای PNG با
پس‌زمینهٔ روشن (شفاف)، لوگو روی پس‌زمینهٔ سبز تیرهٔ جلد می‌نشیند و
زیباتر می‌شود.

اگر لوگویی نگذارید، جلد همچنان ساخته می‌شود — تنها پس‌زمینهٔ
شیب‌دار با نام مداح و نام گنجینه.

## آزمودن جلد

```bash
python -c "import sys; sys.path.insert(0,'.'); from services.tagger import make_cover; make_cover(madah='حاج محمود کریمی', title='شب اول محرم', lyrics='امشب شب عاشوراست', output='cover_test.jpg')"
```

سپس `cover_test.jpg` را ببینید.

## خاموش کردن برچسب‌گذاری خودکار

اگر نمی‌خواهید هر نوای پذیرفته‌شده برچسب بخورد و در گروه دوباره
فرستاده شود، در پایگاه داده این کلید را صفر کنید:

```sql
INSERT INTO settings (key, value) VALUES ('auto_tag', '0')
  ON CONFLICT(key) DO UPDATE SET value = '0';
```
