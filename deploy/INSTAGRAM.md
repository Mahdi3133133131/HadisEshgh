# اینستاگرام — چرا کار نمی‌کند و چطور درست می‌شود

## مشکل چه بود

ربات می‌گفت «این پست خصوصی است»، حال آنکه پست عمومی بود و رباتِ
دیگری همان ویدیو را می‌آورد.

دو سبب داشت، و هیچ‌کدام خصوصی بودنِ پست نبود:

**۱) پیامِ نادرست.** هر خطایی که واژهٔ `login` داشت، «خصوصی است»
خوانده می‌شد. ولی اینستاگرام امروز برای دسترسیِ **ناشناس** هم ورود
می‌خواهد — شرطی همگانی، نه ویژگیِ آن پست. اکنون این دو از هم جدا
شده‌اند و پیامِ درست گفته می‌شود.

**۲) نبودِ نشست.** رباتِ دیگری که آزمودید کوکی دارد؛ برای همین کار
می‌کند. بی کوکی، اینستاگرام تقریباً هیچ چیزی به ما نمی‌دهد.

---

## راه‌حل: کوکی

### 🔴 نخست: حسابِ دوم بسازید

**کوکیِ حسابِ اصلی‌تان را نگذارید.** کوکی یعنی دسترسیِ کامل به آن
حساب. اگر روزی سرور از دستتان در برود، حساب هم می‌رود. و
اینستاگرام حساب‌هایی را که رفتارِ خودکار نشان دهند محدود می‌کند —
بهتر است آن حساب، حسابی باشد که از دست دادنش برایتان مهم نباشد.

### گام‌ها

**۱.** در مرورگر با آن حسابِ دوم وارد اینستاگرام شوید.

**۲.** افزونه‌ای برای بیرون‌دادنِ کوکی نصب کنید — هر افزونه‌ای که
قالبِ **Netscape cookies.txt** بدهد.

**۳.** کوکیِ دامنهٔ `instagram.com` را بیرون بدهید و در سرور
بگذارید:

```bash
# روی سرور
nano /opt/hadis/instagram_cookies.txt     # محتوا را بچسبانید
chmod 600 /opt/hadis/instagram_cookies.txt
chown hadis:hadis /opt/hadis/instagram_cookies.txt
```

**۴.** در `.env` نشانی‌اش را بدهید:

```
INSTAGRAM_COOKIES_FILE=/opt/hadis/instagram_cookies.txt
```

روی Daytona، همان مسیرِ پوشهٔ پروژه:

```
INSTAGRAM_COOKIES_FILE=/home/daytona/hadis/instagram_cookies.txt
```

**۵.** ربات را از نو راه بیندازید.

## نگهداری

**کوکی می‌میرد.** معمولاً چند ماه دوام می‌آورد، ولی اگر از آن حساب
در جای دیگری خارج شوید (logout) همان لحظه باطل می‌شود. وقتی دوباره
پیامِ «اینستاگرام اجازه نداد» دیدید، کوکی را از نو بگذارید.

**yt-dlp را تازه نگه دارید.** پینِ سفتش برداشته شد، چون اینستاگرام
ساختارش را ماه‌به‌ماه عوض می‌کند و استخراج‌گرِ کهنه در چند هفته
می‌میرد:

```bash
cd /opt/hadis
sudo -u hadis .venv/bin/pip install -U yt-dlp
sudo systemctl restart hadis
```

هر دو سه ماه یک بار بس است.

---

## اگر کوکی نگذاشتید

ربات دیگر دروغ نمی‌گوید. می‌گوید اینستاگرام اجازه نداده، و از
کاربر می‌خواهد خودِ ویدیو را بفرستد — که همان کار را می‌کند و
هیچ‌چیز از دست نمی‌رود. جست‌وجو با فایل، هستهٔ کارِ ربات است؛
لینکِ اینستاگرام تنها یک راهِ کوتاه است.
